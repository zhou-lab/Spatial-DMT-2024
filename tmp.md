Counting note:
- `Mapped` and `Mapping rate` below use the fragment/read-pair-unit counts from `{sample}_spatial_barcode_counts.tsv`, generated by `tools/barcode_summary.py`.
- That script skips secondary/supplementary alignments; for paired-end BAMs it counts only R1, and for single-end BAMs it counts every primary record. This keeps the count in one-molecule units and below raw read pairs.
- The curated MultiQC table also reports BAM read-record counts from `samtools flagstat`; those include both R1 and R2 for paired-end samples and can exceed raw read pairs.
- In the reproduced original pipeline, R2 supplies the structure/barcode decision and one selected mate per input pair is carried into the downstream single-end path; it is not strictly whitelist-designed only. The 76.03% `structure_pass / raw pairs` value is pair-level; a raw-DNA-read retention plot must divide that single-mate count by `2 x raw read pairs` (38.02%).
